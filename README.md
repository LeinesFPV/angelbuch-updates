# Angelbuch – Updates

Hier liegen nur die fertigen Versionen der Angelbuch-App. Die App schaut einmal am Tag in `version.json` nach, ob es etwas Neues gibt.

**Aktuelle Version: 1.4** (2026-10-30)

> **Wichtig:** Version 1.4 muss einmalig neu installiert werden (neuer Signaturschlüssel). Vorher die alte App einmal mit Internet öffnen, damit offline gespeicherte Fänge hochgeladen werden. Dann alte App deinstallieren, 1.4 installieren und mit demselben Namen und Passwort anmelden – alle Fänge, Stellen und Gruppen sind wieder da.

[Angelbuch-1.4.apk herunterladen](https://github.com/LeinesFPV/angelbuch-updates/raw/main/Angelbuch-1.4.apk)

## Neu in dieser Version
- Benachrichtigungen bei neuen Fängen funktionieren jetzt
- Neuer Signaturschlüssel: einmalige Neuinstallation nötig

## Installieren
1. APK auf dem Handy herunterladen und öffnen.
2. Android einmal erlauben, Apps aus dieser Quelle zu installieren.
3. Über eine ältere Version installieren: Anmeldung und alle Fänge bleiben erhalten.

Ältere Versionen liegen im Ordner [alte-versionen](alte-versionen).
